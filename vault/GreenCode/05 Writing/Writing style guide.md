# Writing style guide (how the report sections were written)

- Summary: "Approx 200 words"; answer the five hints (idea, useful/unique, what it offers the user, how it operates, why good + deliverable); "reference masters and phd level writing styles online"; include the research question and hypotheses; add ethics / AI accountability in the last paragraph in relation to the dissertation.
- Background: "Approx 300 words"; "use IEEE referencing, focus on top quality academic references, ideaslly include a few references from irish university masters,phd, or final year project dissertations. Use a high level writing style with personal pronouns, humanise the writing using peoples published work as examplkes of style/dialect. id want approx 20 references explored".
- Proposed Approach: "Approx 500 words"; five areas (Research; Requirements Gathering / User Group; Analysis and Design; Implementation; Testing / Evaluation); "use previous instructions and avaialble skills".
- Deliverables: "same writing style as all previous ones, and use sasme skills"; then "humanise this a bit more"; then "shorten it".
- Technical Requirements: "same writing style"; "make this much shorter"; later supplied his own draft to be edited with citations.
- Conclusion: "just give a conclusion of the idea, dont speak about timelines etc"; one sentence ("My project asks whether...") rephrased on request.
- Appendices: Appendix A = "First Similar Piece of Work Review" (Abtahi & Azim), "make this much shorter"; Appendix B = a second review (Bachras & Jacobsen).
- References managed in Zotero via BibTeX files the assistant produced (`greencode-references.bib`, `-additions.bib`, `-energy.bib`) plus a PowerShell PDF downloader; IEEE style recommended inside Zotero/Word so numbering stays correct.
- General: first person, humanised, masters/PhD-level academic register; IEEE numeric citations; every measurement labelled measured or estimated; verification treated as non-negotiable.
- Diagrams and plan for the report: flowchart, UML use case, UML class diagram (docs/diagrams), Gantt chart (SVG/PNG, then Excel "regular flow" version, then a report image) — week 1 w/c 14 Sep 2026, interim report week 10, final submission late April 2027.

## Working method
1. James pastes the template section + hints (word count, questions to answer).
2. Claude drafts in first person, humanised, Masters/PhD register, IEEE numeric citations, Irish theses where relevant.
3. Iterate with short instructions: "humanise this a bit more", "shorten it", "make this much shorter", "rephrase this bit", "does this meet all these hints".
4. New references → BibTeX file for Zotero → full IEEE list reissued with stable numbering.
