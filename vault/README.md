# GreenCode Obsidian vault

`vault/GreenCode/` is an Obsidian vault: every note about the project (purpose, research design, how the code works, how to run it, the report sections, references, decisions, and the AI-assistance conventions).

Use it one of two ways:

1. **Open as its own vault** — Obsidian → *Open folder as vault* → `GreenCode-app\vault\GreenCode`.
2. **Drop it into an existing vault** — copy the `GreenCode` folder into your vault; all links are relative `[[wiki-links]]` so nothing breaks.

Start at `00 Home.md`. Images and the Word walkthrough live in `_assets/`.
